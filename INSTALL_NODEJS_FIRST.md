## 🚀 Pasos para Instalar Node.js (5 minutos)

### **PASO 1: Descargar** 📥

1. Ve a: **https://nodejs.org/**
2. Descarga la versión **LTS** (Long Term Support)
3. Archivo: `node-v20.x.x-x64.msi` (Windows 64-bit)

> 💡 **LTS** es la versión recomendada para producción

---

### **PASO 2: Instalar** 🔧

1. **Doble click** en el archivo `.msi` descargado
2. Click en **Next** (siguiente)
3. Aceptar licencia → **Next**
4. Ubicación por defecto → **Next**
5. **Importante:** Dejar todas las opciones marcadas:
   - ✅ Node.js runtime
   - ✅ npm package manager
   - ✅ Online documentation shortcuts
   - ✅ **Add to PATH** (crucial)
6. Click en **Next** → **Install**
7. Esperar instalación (2-3 minutos)
8. Click en **Finish**

---

### **PASO 3: Verificar Instalación** ✅

1. **Cerrar TODAS las terminales** abiertas (importante)
2. Abrir **nueva terminal** (PowerShell o CMD)
3. Ejecutar:

```bash
node --version
```

**Resultado esperado:**
```
v20.11.0
```

4. Verificar npm:

```bash
npm --version
```

**Resultado esperado:**
```
10.2.4
```

## ❓ Troubleshooting

### ⚠️ "node no se reconoce como comando"

**Causa:** Node.js no está en el PATH o terminal no se reinició

**Solución:**
1. Cerrar TODAS las terminales
2. Abrir nueva terminal
3. Intentar de nuevo

Si persiste:
1. Desinstalar Node.js
2. Reinstalar marcando "Add to PATH"

### ⚠️ No puedo instalar (permisos)

**Solución:**
1. Click derecho en instalador
2. "Ejecutar como administrador"

### ⚠️ Error durante instalación

**Solución:**
1. Descargar de nuevo el instalador
2. Verificar que sea la versión correcta (64-bit)
3. Desactivar antivirus temporalmente
