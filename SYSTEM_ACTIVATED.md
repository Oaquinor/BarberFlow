# SYSTEM_ACTIVATED.md — registro histórico

Este archivo conserva una guía de estado local reportada el 30 de mayo de 2024. Sus instrucciones de inicio, endpoints, número de modelos, gratuidad y afirmaciones de preparación para producción están obsoletas y no deben usarse como evidencia del estado actual.

Para el estado real del producto, stack MySQL, módulos, validaciones y pendientes, consulta [PROJECT_SUMMARY.md](PROJECT_SUMMARY.md). Para iniciar el servicio WhatsApp vigente, consulta [whatsapp-service/README.md](whatsapp-service/README.md) y [QUICK_START_WHATSAPP.md](QUICK_START_WHATSAPP.md).

El gateway WhatsApp actual es opcional, requiere secreto de API, una sesión vinculada y configuración externa. No se ha verificado entrega real de mensajes en producción. Los avisos se procesan desde una bandeja durable MySQL.
